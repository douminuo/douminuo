# 도우미누오 (크롬 확장 프로그램 v2.0.1)

**한국어** | [English](README.en.md)

## 소개
<img src="assets/readme/overview.png" alt="도우미누오 적용 화면" style="max-width: 100%; height: auto;" />

> **도우미누오**는 [스마트누오](https://smartnuo.com) 사용자를 위한 비공식 편의성 확장 프로그램입니다.

- 내 파티의 결정력과 내구력을 실시간으로 확인
- 내 포켓몬의 스피드 추월컷을 실시간으로 확인
- 샘플과 파티를 박스에 저장하고 나중에 다시 불러오기
- 내 포켓몬을 계산기에 자동 입력
- 내 파티와 포켓몬 샘플을 다른 곳에 올리기 쉽게 텍스트로 복사
- Pokémon Showdown / PokePaste 스타일의 영문 변환 및 복붙 지원

---

## 설치

### 크롬 웹 스토어 (권장)

[크롬 웹 스토어](https://chromewebstore.google.com/detail/bmgohocnliecjcefhnaakbdcfjcdmoan?utm_source=item-share-cb)에 들어가 **Chrome에 추가** 버튼을 누르면 설치가 완료됩니다.
자동 업데이트를 지원합니다.

### GitHub 릴리즈에서 설치

1. GitHub 저장소의 Releases에서 원하는 버전을 고릅니다.
2. 해당 버전에 첨부된 `douminuo-x.x.x.zip`을 내려받고 압축을 풉니다.
3. 크롬에서 확장 프로그램 창을 엽니다.
    - 방법 1: 주소창에 `chrome://extensions`를 입력합니다.
    - 방법 2: 오른쪽 위 점 세 개(더보기) → 확장 프로그램 → 확장 프로그램 관리를 클릭합니다.
4. 오른쪽 위 개발자 모드를 켭니다.
5. 왼쪽 위 압축해제된 확장 프로그램 로드를 누릅니다.
6. 위 3번 압축을 푼 폴더를 선택합니다.
7. 도우미누오 아이콘이 보이면 설치 완료입니다.

업데이트할 때는 새 릴리즈 zip으로 같은 절차를 반복하면 됩니다.
압축을 풀어 기존 폴더를 덮어쓴 뒤 `chrome://extensions`에서 해당 확장 프로그램의 새로고침(↻)을 눌러도 됩니다.

## 기능 소개 및 사용법

### 파티 결정력 및 내구력 표시

<img src="assets/readme/02-power-bulk-annotations.png" alt="파티 결정력 및 내구력 표시" style="max-width: 100%; height: auto;" />

각 기술 옆에 결정력을, 카드 우상단에 내구력을 표시합니다.

### 스피드 추월표

<img src="assets/readme/03-speed-table.webp" alt="스피드 추월표" style="max-width: 100%; height: auto;" />

내 포켓몬이 스피드 몇 족까지 추월 가능한지 확인할 수 있습니다.

### 샘플/파티 저장 및 불러오기

<img src="assets/readme/04-box.webp" alt="박스" style="max-width: 100%; height: auto;" />

샘플과 파티를 저장하여 박스에 보관할 수 있습니다.
페이지 가운데 **박스** 버튼을 클릭해 박스에 접근할 수 있으며, 저장한 샘플 및 파티를 불러올 수 있습니다.

샘플은 최대 100개, 파티는 최대 20개까지 보관 가능합니다.

### 계산기 자동 입력

<img src="assets/readme/01-calc-auto-fill.webp" alt="계산기 자동 입력" style="max-width: 100%; height: auto;" />

파티에 있는 포켓몬을 계산기에 자동으로 빠르게 넣을 수 있습니다.
박스에서 미리 저장해둔 샘플을 선택해 넣을 수도 있습니다.

### 샘플 텍스트 변환

<img src="assets/readme/05-text-copy.webp" alt="샘플 텍스트 변환" style="max-width: 100%; height: auto;" />

내 파티 혹은 샘플을 다른 커뮤니티 및 블로그에 올리기 쉽게 텍스트로 변환해 복사해줍니다.
환경설정에서 포함하고 싶은 항목을 켜고 끌 수 있습니다.
- **공유 URL:** 이 URL을 통해 파티 페이지에서 샘플로 변환해 불러올 수 있습니다.
- **실수치:** 실수치를 추가합니다. 
- **결정력:** 각 기술에 결정력을 추가합니다. 지닌물건과 특성의 효과를 반영합니다.
- **내구력:** 물리내구 및 특수내구를 추가합니다. 지닌물건과 특성의 효과를 반영합니다.
- **Showdown:** Pokémon Showdown / PokePaste 형식으로 변환합니다.

### 환경설정

박스 오른쪽 위 설정 버튼, 또는 크롬 툴바의 도우미누오 아이콘을 클릭해 환경설정에 들어갈 수 있습니다.
원하는 기능을 켜고 끌 수 있습니다.
